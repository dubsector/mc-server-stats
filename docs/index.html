Data sources

  • bStats for server counts per version and the ecosystem breakdown
  • PaperMC Fill API for Paper and Folia build channels
  • Leaf build API for Leaf build channels
  • Version-string heuristic for Purpur, which has no channel API

Notes

  • Data refreshes once a day, shortly after midnight UTC
  • bStats reports two kinds of counts. The global server-software chart files each server under exactly one name. Each project's own bStats page also receives pings from downstream forks, so a Purpur server counts toward Paper's page too and those numbers overlap across projects
  • Everything defaults to the global count, where each server is counted once. The "Incl. forks" button on a card switches it to the project's own counter and back
  • Version breakdowns and per-version trends only exist on each project's own page, so those always include downstream forks. bStats does not publish a fork-free version split
  • Per-version history accumulates from July 10, 2026. bStats only exposes current snapshots, so earlier dates cannot be backfilled
  • The ecosystem panel is a current snapshot without version-level detail
