Data sources

  • bStats for server counts per version and the ecosystem breakdown
  • PaperMC Fill API for Paper and Folia build channels
  • Leaf build API for Leaf build channels
  • Version-string heuristic for Purpur, which has no channel API

Notes

  • Data refreshes once a day, shortly after midnight UTC
  • Per-version history accumulates from July 10, 2026. bStats only exposes current snapshots, so earlier dates cannot be backfilled
  • The ecosystem panel is a current snapshot without version-level detail
